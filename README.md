# Next.js Personal Portfolio

A responsive portfolio built with Next.js App Router and ready for Vercel.

## Customize

Update the name, biography, project details, email address, and social links in `index.html`.

## Preview locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, select **Add New → Project** and import the repository.
3. Vercel will automatically detect **Next.js** and configure the build.
4. Select **Deploy**.

You can also deploy with the Vercel CLI by running `vercel` from this directory.
